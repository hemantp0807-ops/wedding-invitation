Wedding invitation (pro) - project files

index.html : content (names, parents, venue, links)
style.css  : colours (:root variables), layout, backgrounds
script.js  : events list (E array), calendar, language toggle, auto-scroll (SPEED = pixels/second)
assets/    : hero.jpg (opening painting), foot.jpg (footer), tile.jpg (paper texture),
             vineL/vineR.png, cornerL/cornerR.png (transparent decorations)

Replace any file in assets/ with a better one of the same name to upgrade the look.
Preview: open index.html in a browser (internet needed for Google Fonts).
